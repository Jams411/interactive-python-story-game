# Interactive Python Story Game

## Overview
This is a beginner Python project that creates an interactive text-based story using user input. The project was built to practice basic Python concepts such as print statements, input, variables, functions, and simple program flow.

## Skills Practiced
- Python basics
- User input
- Variables
- Functions
- String formatting
- Interactive storytelling

## File
- `Dynamic_Movie_Genre_Introduction.ipynb`

## Note
This project is an early Python learning exercise and is intentionally simple.
