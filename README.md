# Interactive Python Story Game

## Overview
A beginner-friendly interactive Python storytelling project built using user input, conditional logic, formatted output, and dynamic text generation. The game creates humorous and randomized story scenarios based on player responses inside a Jupyter Notebook environment.

## Play Online
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Jams411/interactive-python-story-game/blob/main/Interactive_Python_Story_Game.ipynb)

## Concepts Practiced
- Python fundamentals
- Variables
- User input handling
- String formatting
- Conditional logic
- Program flow
- Interactive storytelling

## Features
- Personalized story generation
- Dynamic user-driven prompts
- Interactive console gameplay
- Humorous randomized storytelling
- Beginner-friendly Python project

## Requirements
- Python 3
- Jupyter Notebook, JupyterLab, or Google Colab

## How to Run
1. Open the notebook file:
   `Interactive_Python_Story_Game.ipynb`

2. Run the notebook cells from top to bottom.

3. Enter your responses when prompted.

4. Watch the story dynamically generate based on your inputs.
